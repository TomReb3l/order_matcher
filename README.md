# OrderMatcher

Εφαρμογή Python με CustomTkinter για:
- φόρτωση PDF διαταγής
- φόρτωση Excel δύναμης Υπηρεσίας
- σύγκριση και εύρεση κοινών προσώπων
- προβολή αποτελεσμάτων σε καρτέλα
- εξαγωγή σε Word και Excel

## Τι κάνει

1. Διαβάζει το PDF της διαταγής σαν "οπτικό πίνακα" και όχι σαν κανονικό Excel table.
2. Εντοπίζει εγγραφές με βάση το pattern:
   - Α/Α
   - Μητρώο
   - Επώνυμο
   - Όνομα
   - Πατρώνυμο
3. Φορτώνει το Excel της δύναμης και βρίσκει μόνο του τη γραμμή επικεφαλίδων.
4. Κάνει σύγκριση με προτεραιότητα:
   - πρώτα με **Μητρώο**
   - έπειτα με **Επώνυμο + Όνομα + Πατρώνυμο** για όσους δεν βρέθηκαν με μητρώο
5. Εμφανίζει:
   - κοινούς
   - άτομα που υπάρχουν μόνο στη Διαταγή
   - άτομα που υπάρχουν μόνο στο Excel
6. Κάνει εξαγωγή αναφοράς σε Word.

## Εγκατάσταση

Σε Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Αν δεν επιτρέπεται το activation script:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## Δημιουργία EXE

Τρέξε το `build_exe.bat` ή δώσε χειροκίνητα:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --name OrderMatcher app.py
```

Το τελικό αρχείο θα δημιουργηθεί στο:

```text
dist\OrderMatcher.exe
```

## Σημειώσεις ακρίβειας

- Η κύρια ταύτιση γίνεται με **Μητρώο**.
- Η ονομαστική ταύτιση χρησιμοποιείται μόνο συμπληρωματικά.
- Το πρόγραμμα κανονικοποιεί ελληνικά ονόματα:
  - κεφαλαία
  - αφαίρεση τόνων
  - καθαρισμός περιττών χαρακτήρων
- Αυτό μειώνει τα λάθη από μικρές διαφορές γραφής.

## Αρχεία δοκιμής που χρησιμοποιήθηκαν

Το app σχεδιάστηκε πάνω σε δοκιμή με:
- `διαταγη.pdf`
- `DynamhYpiresias.xls`

Από αυτό το ζευγάρι βρέθηκαν 2 κοινά άτομα με ταύτιση από μητρώο στην αρχική δοκιμή.

## Μπορεί να χρησιμοποιηθεί γενικά για σύγκριση εγγραφών;

Ναι, αλλά με μία βασική προϋπόθεση: τα δύο αρχεία πρέπει να περιέχουν κοινά αναγνωριστικά πεδία, όπως Μητρώο, Επώνυμο, Όνομα και προαιρετικά Πατρώνυμο.

Η εφαρμογή είναι ήδη κατάλληλη για γενική σύγκριση εγγραφών όταν:
- υπάρχει μοναδικό αναγνωριστικό, κατά προτίμηση Μητρώο
- τα δεδομένα είναι σε μορφή λίστας εγγραφών
- το PDF ακολουθεί παρόμοια δομή γραμμών με αριθμό, μητρώο και ονομαστικά πεδία

Για τελείως διαφορετικά έγγραφα ή άλλες δομές PDF, θα χρειαστεί προσαρμογή του parser.
